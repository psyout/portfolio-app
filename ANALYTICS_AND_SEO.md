# Analytics and SEO setup

SEO helps people discover the site. Google Analytics tells you when people visit it.

## Google Analytics

1. In [Google Analytics](https://analytics.google.com/), create a GA4 property and a Web data stream for `https://felipegonzalez.dev`.
2. Copy the Measurement ID, which starts with `G-`.
3. Add it to the production deployment as an environment variable:

   ```text
   NEXT_PUBLIC_GA_ID=G-YOUR-ID-HERE
   ```

4. Redeploy, visit the site, and check **Reports > Realtime**. Analytics cannot recover visits from before tracking was installed.

## Google Search Console

1. Verify `felipegonzalez.dev` as a Domain property.
2. After deploying this project, open **Indexing > Sitemaps**.
3. Submit `sitemap.xml`.
4. Use **URL inspection** to request indexing for the homepage.

Search Console reports Google Search impressions, clicks, queries, and indexed pages. Data usually takes a few days to appear.

## Included in the project

- Google Analytics loads only when `NEXT_PUBLIC_GA_ID` exists.
- Search metadata, canonical URL, social sharing metadata, and Person structured data.
- `/robots.txt` and `/sitemap.xml`, generated by Next.js.
